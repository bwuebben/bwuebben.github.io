MODEL & REFERENCES

What is exact. What is schematic.

The curves and their intersections use explicit formulas. The knot drawing is a planar braid-closure model; the bigon animation is a separate local schematic. This is a teaching explorer, not an arbitrary-knot character-variety solver.

Coordinate convention (HHK)

a = i, b = eγki, c = eθki, d = e(θ−γ)ki; ba = cd.

Trefoil boundary curve

L₁(t) = (t, −2t), 0 ≤ t ≤ π.

Earring & holonomy-perturbed trivial tangle

L₀(β) = (β + π/2 + ε sin β, β + π/2 − ε sin β).

The slider uses 0.02 ≤ ε ≤ 0.22 radians, plus a degenerate ε = 0 comparison. Intersections solve 3β + 3π/2 + ε sin β = 2πn, n = 1, 2, 3. Labels x₁ and x₂ distinguish branches; they do not assert an absolute grading or the authors’ ± convention.
