THE COMPRESSION

Each branch becomes one representative portfolio. Its children are allocated using two variances, one covariance and, for the signal-aware methods, two expected returns. Local optimality in these representatives does not imply global Markowitz optimality.

WHAT CONVERGENCE MEANS

For positive-definite Σ and 0 ≤ γ ≤ 1, the unlimited Gauss–Seidel iteration converges to Pγ−1μ. This is a numerical guarantee, not a guarantee of investment performance. Total work depends on the number of sweeps; shrinking correlations also changes the portfolio being solved for.

ILLUSTRATIVE MONTE CARLO

40 seeded repetitions at 21 γ values. Each repetition draws T independent Gaussian return vectors from the current covariance and adds independent Gaussian noise to the current signal. Each covariance estimate receives a 10⁻⁸ diagonal ridge. The curve is mean population Sharpe μtrueᵀw / √(wᵀΣtruew) of the directly solved shrinkage portfolio. This evaluates the CRISP fixed point. It is not a historical backtest, a replication of the paper’s numerical tables, or an implementable out-of-sample tuning rule. The best γ shown uses population information for teaching.

02 / THE IDEAS BEHIND THE CONTROLS

Keep the structure.
Let the signal in.

01

HRP-μ

Represent each cluster with signed inverse-variance weights. Carry the expected return into a two-branch allocation, and preserve the signal direction at the leaves.

At γ = 0 and μ = 1, this recovers the HRP rule implemented here on the same tree.

02

HRP-Σμ

Build representative portfolios from the bottom up. At each node, solve a local two-portfolio mean–variance problem and normalize by gross exposure, |αL| + |αR|.

The positive denominator preserves the orientation of the local solution. This recursive construction need not reproduce standard HRP exactly.

03

CRISP

Remove the hierarchy and solve a shrunk covariance system. Keep marginal variances, attenuate correlations, and use sequential coordinate updates to reach the solution.

At convergence the result equals direct Markowitz on Pγ. Shrinkage and the numerical solver are separate choices.
